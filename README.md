# Fake--News-Detection-Streamlit-project
An NLP-based ML application that classifies news as fake or real using TF-IDF. It compares Logistic Regression, Naive Bayes, Linear SVM, and Random Forest using accuracy, precision, recall, F1-score, and a confusion matrix. The best model is saved and integrated with Streamlit for single and batch predictions.
